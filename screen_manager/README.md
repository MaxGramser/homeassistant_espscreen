**Touch screens for Home Assistant. A screen for every room, one simple editor.**

Tessera is the new name for ESP Screens: the same app, the same screens, a new name and logo.
Find your Home Assistant entities, arrange up to 64 tiles over eight pages, and push changes
to a CYD, Guition or Waveshare screen without reflashing. Includes installation help, a unique
per-device YAML, and support for multiple screens.

Open **Tessera** in the sidebar after installation. See **Documentation** for the first install.
The app uses Home Assistant Ingress and needs no login or token of its own.
