# Open Nextion Genius ONX3248G035

The ONX3248G035 is a 3.5-inch ESP32-S3R8 panel with a 320 x 480 ST7796 display,
CST826 capacitive touch, 16 MB flash and 8 MB octal PSRAM. Its board key is
`onx3248g035`. Support is experimental and follows [wishlist #171](https://tessera-maxgramser.on-forge.com/wishlist/171).

## Accessories

A battery, camera, microphone and speaker are not supplied with the board. Each
is an optional accessory purchased separately. The board has battery charging
and voltage-sensing circuitry and interfaces for accessories; these do not mean
the corresponding accessories are included.

Battery monitoring in this profile is intended for a separately connected
battery. Remote pictures received from Home Assistant need no camera attached
to the screen. Attached camera, microphone and speaker operation is not enabled
by this profile.

## Supported hardware

This profile targets the current board circuit described below and the manufacturer's
V1.2 schematic. Earlier units with different circuitry are not covered. A PCB revision
label alone has not been established as a reliable way to distinguish all units.
Check the circuit against these connections before treating an earlier unit as supported.

| Function | Connection |
|---|---|
| Display SPI | Clock GPIO5, MOSI GPIO1, CS GPIO2, DC GPIO3; no MISO |
| Backlight | GPIO6, active high, PWM at 10 kHz |
| Shared I2C | SDA GPIO8, SCL GPIO7, 100 kHz |
| Touch | CST826 at address `0x15`, ESPHome `cst816`, polled every 16 ms |
| GPIO expander | PCF8574A at address `0x38` |
| Display and touch reset | PCF8574 P5, driven once by the display |
| Battery voltage | GPIO4 through R31 = 1 Mohm and R32 = 2.2 Mohm |
| Charging status | PCF8574 P2, high while charging after the board's inverter |
| USB serial | UART0 through the CH340K bridge, 115200 baud |

The SPI display uses mode 0 at 80 MHz, BGR colour order, no colour inversion and
an X mirror. Touch coordinates use the shared defaults without another mirror.
GPIO3 is a strapping pin; ESPHome reports its usual warning. PSRAM runs in octal
mode at 40 MHz.

Unused expander ports stay released high. The touch interrupt is not used because
it reaches the expander rather than an ESP32 interrupt pin. The display's reset
also reaches the touch panel, so the touch driver must not reset it independently.

## Layout and rotation

The standard look uses the panel's calculated density, 164.825 dpi. The default
landscape canvas is 480 x 320 with a 2 x 2 grid; portrait is 320 x 480 with a 1 x 3
grid. The default landscape angle is 270 degrees, with portrait at 0 degrees.
The editor's Grid control changes landscape and portrait; Rotation adds a half
turn within the selected orientation, as on other rectangular screens.

The profile allows up to 128 tiles, 24 pages and 12 top-bar items. These are
ceilings, not a promise that every combination fits: the runtime memory budget
still decides what a layout can hold. The initial LVGL buffer is 12%.

## Battery

The profile reuses the shared battery ADC and voltage packages. The voltage
multiplier is `(1 + 2.2) / 2.2`, approximately 1.45454545. Battery Level is the
shared linear estimate between 3.3 V and 4.2 V, clamped to 0 to 100%. It is not a
fuel gauge or a measured discharge curve, and voltage while charging affects it.

Battery-powered operation, voltage against a meter, and both USB charging-state
transitions have been checked on the supported circuit. Full-charge termination,
a complete discharge curve and battery-absent readings remain unverified. The
`battery` and `battery_charging` device classes provide the normal top-bar item
and Home Assistant entities without a separate board-specific UI.

## Features and limits

Display, touch, layout delivery, multiple pages, dragging controls, both
orientations, remote still pictures, brightness, standby and touch wake, and a
full cold restart have been checked on the supported board circuit. The self-test
action is included; its
inclusion alone does not mean its diagnostic suite has been run.

The firmware profile includes the picture package for Home Assistant camera snapshots,
media covers and other remote stills. This is separate from capturing a picture
with an attached camera. Audio, RTC, MicroSD and attached camera or microphone
support are not enabled by this profile.

UI snapshots are not enabled: the current shared snapshot implementation samples
a fixed 480 x 480 area, which exceeds this panel in either orientation. Supporting
snapshots needs a separate correction to that shared implementation.

Long-duration operation and a before/after memory comparison remain unverified.
Keep the catalog status experimental until broader acceptance is complete.

## Build and references

A local checkout builds `checkout/onx3248g035.yaml` with private credentials in
`checkout/secrets.yaml`, as described in [checkout/README.md](../checkout/README.md).
The generated remote entry is `packages/onx3248g035.yaml`; it becomes available
from the upstream development channel after the support is merged, and from the
stable channel after a release. Do not copy credentials into the board file.
