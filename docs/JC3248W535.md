# Guition JC3248W535, 3.5 inch, 480 × 320 (new)

A 3.5-inch board from Guition (**JC3248W535**, often sold with an enclosure as **JC3248W535C**): a 320 x 480 panel
with an **AXS15231B** driver on a four-line QSPI bus, **capacitive touch** read from the same AXS15231B over I2C, on
an ESP32-S3 with 16 MB flash and 8 MB octal PSRAM. It has the glass of the Waveshare 3.5-inch, so the same density
and grid, and the PSRAM that board lacks, so camera pictures work.

The board is **new**: its file was built from ESPHome's own model for this board and the configuration a community
member shared for it (GitHub #54). That community member installed it from ESP Screens on a real unit, and it worked with no
changes to the board file. The project has not tried it on a unit of its own yet.
If you have one, [tell others how it went](https://tessera-maxgramser.on-forge.com/community/share?type=installation&board=jc3248w535).

## Install

Update ESP Screen Manager and choose **Guition · 3.5 inch** (JC3248W535) in **New screen**. Follow
[Easy setup](EASY_SETUP.md) to create a profile with its own name, Wi-Fi references and unique API/OTA keys, then
flash it over USB or download the firmware for ESPHome Web. There is no touch calibration: the touch panel reports
pixels.

The remote package is `packages/jc3248w535.yaml`; the checkout entry is `checkout/jc3248w535.yaml`. Both combine
`packages/core.yaml` with `packages/boards/guition-jc3248w535.yaml`.

A screen you set up by hand from the shared packages needs the board's `BOARD_ID` and a `DEVICE_NAME` equal to its
`esphome: name:`: ESP Screens knows a screen by the two, and a screen without them can be seen but never takes tiles.
Building from `packages/jc3248w535.yaml` sets both.

## Layout and capabilities

- Lying down: 480 x 320, two by two cells, as on the Waveshare 3.5-inch. Standing up: 320 x 480, one column of three.
- The standard look at 165 dpi (577 diagonal pixels over 3.5 inches).
- Capacitive touch, polled every 20 ms; the board has no interrupt line wired to it.
- The backlight is a PWM pin (GPIO1) at 150 Hz with a small floor, as on the 4-inch Guition: dimming, standby,
  night and an alert's flashes work.
- Camera pictures, live camera tiles and media artwork, from the PSRAM.
- LVGL draws through a 25 % buffer. Read `sensor.<screen>_heap_free` with a full layout; under 40 KB is too little.

## Pins

| Part | Pins |
| --- | --- |
| QSPI bus (display) | CLK GPIO47, data GPIO21, GPIO48, GPIO40, GPIO39, CS GPIO45 |
| I2C bus (touch, 0x3B) | SDA GPIO4, SCL GPIO8 |
| Backlight | GPIO1 |

The board also has a battery connector with a voltage divider on GPIO5. The board file leaves it out; a screen's
Override YAML can add an `adc` sensor on it ([Hardware-specific YAML overrides](EASY_SETUP.md)).

## Tried on a real unit

- Installed from ESP Screens on firmware 0.4.0, lying down, taking tiles, with a live camera tile on the glass.
- Taps land where they should with none of the touch axes mirrored or swapped, the board file's defaults. A screen
  whose taps do land mirrored or swapped can set `TOUCH_MIRROR_X`, `TOUCH_MIRROR_Y` or `TOUCH_SWAP_XY` in its own
  YAML ([Hardware-specific YAML overrides](EASY_SETUP.md)).
- Memory after 16 minutes with a full page and a camera tile: about 142 KB of internal heap free (120 KB at the
  lowest), and 7.7 MB of PSRAM free.
